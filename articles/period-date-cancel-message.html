生理でデートを断りたいときの伝え方｜彼氏に気まずくならない言い方と予定の立て方

2026-10-03 公開 ・ 2026-10-03 更新 ・ WithCare

結論

生理でデートを断りたいときは、「体調が悪いこと」「今日は会うのが難しいこと」「別の日に会いたいこと」の3点を短く伝えると、相手に誤解されにくくなります。生理と言いにくい場合は「体調不良」とだけ伝えても問題ありません。代わりの日程か過ごし方を添えると、断られた側も安心できます。

この記事の要点

  • 生理を理由に予定を変えることは失礼ではなく、体調を優先してよい
  • 伝えるのは「理由・今の状態・代わりの予定」の3点で十分
  • 生理と言いにくい日は「体調が悪い」だけでも気持ちは伝わる
  • 中止ではなく「おうちデート」や「短時間」への変更も選べる
  • 生理の予定を共有しておくと、デートの日程を前もって調整できる

目次

  1. 生理でデートを断るのは失礼にあたる？
  2. 生理でデートを断るとき、彼氏にどう伝えればいい？
  3. 生理と言いにくいときは、どこまで伝えればいい？
  4. デートを中止せずに予定を変えるにはどうすればいい？
  5. 生理とデートの日程が重ならないように予定を立てるには？

生理でデートを断るのは失礼にあたる？

生理を理由にデートを断ることは失礼ではありません。体調を優先して予定を変えることは、二人の関係を長く続けるための自然な判断です。

体調による予定変更とは、体調を理由に約束の日時や内容を変えることです。理由を伝えずに当日に約束を破る「ドタキャン」とは異なります。

生理中の症状は、人によっても月によっても変わります。腹痛・腰痛・頭痛・眠気・だるさなどがあり、本人の気持ちの持ちようで軽くできるものではありません。

  • 痛みがあるまま外出すると、デートを楽しめずにお互いが気をつかう
  • 早めに伝えれば、相手も予定を組み直せる
  • 無理をしない姿勢を見せることで、相手も体調不良を伝えやすくなる

痛みが強くて日常生活に支障がある、いつもと症状が違うといった場合は、自己判断せずに婦人科などの医療機関へ相談してください。

生理でデートを断るとき、彼氏にどう伝えればいい？

「体調が悪い」「今日は会うのが難しい」「別の日に会いたい」の3点を短く伝えるのが基本です。謝りすぎず、会いたい気持ちを添えると誤解が生まれにくくなります。

伝えるときの3つの要素

  1. 理由：生理、または体調不良であること
  2. 今の状態：外出が難しい、長時間は難しいなど
  3. 次の提案：別の日程、または別の過ごし方

状況別の例文

状況 例文
前日に伝える 「明日、生理が来そうで体調が不安なの。もし大丈夫なら来週の土曜にずらせないかな？」
当日の朝に伝える 「ごめんね、生理でお腹が痛くて今日は出かけるのが難しそう。楽しみにしてたから、元気な日に改めて会いたい」
生理と言いにくい 「今日ちょっと体調が悪くて、外に出るのがきついんだ。別の日にしてもらえるとうれしい」
会いたい気持ちはある 「生理で遠出はきついんだけど、家でゆっくりなら会えそう。どうかな？」

「ごめんね」は1回で十分です。謝罪を重ねるより、次に会う日や過ごし方を具体的に出すほうが、相手は前向きに受け取りやすくなります。

生理と言いにくいときは、どこまで伝えればいい？

生理であることまで伝える必要はなく、「体調が悪い」だけでも十分です。伝える範囲は自分が話しやすい段階を選んでかまいません。

生理のことをどこまで話すかは、付き合った期間や二人の関係によって変わります。正解は一つではないため、自分が無理なく話せる範囲を選んでください。

伝える範囲 例 向いている場面
体調不良のみ 「体調が悪くて」 付き合い始めで話しにくいとき
生理であること 「生理でお腹が痛くて」 理由をはっきり伝えたいとき
症状と希望 「生理2日目で腹痛が強いから、今日は家で休みたい」 状態を理解してほしいとき
  • 毎月同じ時期に予定が合わない場合は、一度「生理の時期は体調が崩れやすい」と伝えておくと、次回から説明が短くて済む
  • 落ち着いて話せる日に伝えるほうが、当日に体調が悪い状態で説明するより負担が小さい

デートを中止せずに予定を変えるにはどうすればいい？

「中止」ではなく「内容の変更」を提案すると、会えるうえに体への負担も減らせます。移動・時間・場所の3つを調整するのが目安です。

体調によっては、会うこと自体はできても、遠出や長時間の外出がつらい日があります。予定をまるごと取りやめる前に、内容を変える選択肢を考えてみてください。

元の予定 変更案
テーマパーク・遠出 近所のカフェやおうちデート
1日中のデート ランチだけ、2〜3時間だけ
海・プール・温泉 映画館や水族館など座って過ごせる場所
外食のはしご テイクアウトや宅配で家ごはん
  • トイレの場所を気にせず過ごせる場所を選ぶと安心しやすい
  • 「途中で疲れたら早めに帰るかも」と先に伝えておくと、当日に切り上げやすい

生理とデートの日程が重ならないように予定を立てるには？

次の生理の予定日を二人で把握しておくと、大事なデートや旅行を体調の安定しやすい時期に組みやすくなります。予定日はあくまで目安として扱います。

直前に断る回数を減らすには、デートの日程を決める段階で生理の予定日を考慮するのが効果的です。予定日を彼氏にも共有しておけば、毎回説明しなくても日程の相談がしやすくなります。

予定を立てるときの手順

  1. 自分の生理日を記録し、次の予定日の目安を把握する
  2. 予定日の前後を、遠出や旅行を避けたい期間として二人で共有する
  3. 旅行や記念日などの大事な予定は、予定日から離れた日を候補にする
  4. 周期がずれた場合に備えて、変更しやすい予約方法を選ぶ

周期の予測は過去の記録をもとにした目安であり、実際の生理日とずれることがあります。周期が大きく乱れる、生理が長く来ないといった場合は医療機関へ相談してください。

生理周期を二人で共有する方法の一つが、カップル向けの共有アプリです。たとえば「WithCare」では、生理日と周期予測をカレンダーで確認でき、招待コードでペアリングしたパートナーと記録を共有できます。共有する範囲は自分で選べます。

彼氏から気まずい反応が返ってきたらどうする？

相手が戸惑った反応をした場合は、生理中の体調について知らないだけのこともあります。責め合わず、体調と希望を落ち着いて伝え直すのが基本です。

生理の経験がない相手にとっては、生理中の体のつらさを想像しにくいことがあります。素っ気ない返信があっても、すぐに「わかってくれない」と結論づける必要はありません。

伝え直すときのポイント

  • 体調が落ち着いた日に、会えなかった理由をあらためて説明する
  • 「こうしてくれるとうれしい」と具体的な希望を伝える（例：「当日は返信が遅くなっても待ってほしい」）
  • 予定を変えたことへのお礼を伝える（例：「ずらしてくれてありがとう、助かった」）

彼氏側ができる気づかいの例

  • 「無理しないでね」「別の日にしよう」とすぐに返す
  • 会う場合は家や近場を提案する
  • 体調を確認する短いメッセージを送る

生理の話題は、どちらか一方だけが我慢するものではありません。お互いに伝え方と受け取り方を少しずつ合わせていくことで、次から予定の相談がしやすくなります。

よくある質問

生理でデートを断るのは何日前に伝えるのがいいですか？

予定日が近いとわかった時点で、できるだけ早めに伝えるのが目安です。前日や当日の朝でも、理由と代わりの予定を添えれば相手は予定を組み直せます。体調は当日に変わることもあるため、無理に早く決めすぎる必要はありません。

生理と正直に言わずに断ってもいいですか？

問題ありません。「体調が悪い」「今日は外出がつらい」と伝えるだけでも、予定を変えたい気持ちは十分に伝わります。生理であることを話すかどうかは、自分が話しやすいタイミングで決めてかまいません。

生理を理由に毎月デートを断るのは迷惑ですか？

体調を優先することは迷惑ではありません。毎月同じ時期に体調が崩れやすい場合は、一度その傾向を伝えておくと、予定日を避けて日程を組めるようになります。症状が重い場合は医療機関への相談も検討してください。

周期予測アプリの予定日は正確ですか？

周期予測は過去の記録をもとにした目安であり、実際の生理日とずれることがあります。予定を立てる参考として使い、避妊や妊娠の判断には使わないでください。周期が大きく乱れる場合は医療機関へ相談してください。
